# test-body

```json
{
  "misses": "production sites.",
  "settingsTracedTo": "the edition: backwards compatibility for adopters since the npm release."
}
```

JSON text made or read in a test file. These run with the other [test-body checks](../../../README.md#checks-the-test-body-checks), which share their scope, editions and settings.

## Flags

### Serialising or parsing JSON
`JSON.stringify` or `JSON.parse`. Edition 2 adds it.
