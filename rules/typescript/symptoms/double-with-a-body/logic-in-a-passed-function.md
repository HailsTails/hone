A construct any other test-body check flags, inside a function a test passes on. These run with the other [test-body checks](../../../README.md#checks-the-test-body-checks), which share their scope, editions and settings.

## Flags

### Logic inside a function the test passes on
A function a test writes as a property or method of an object literal, gives to `vi.fn`, `mockImplementation` or `mockImplementationOnce`, or passes straight to a function it calls in its own body, holding a construct another test-body check flags. The edition is that construct's.
