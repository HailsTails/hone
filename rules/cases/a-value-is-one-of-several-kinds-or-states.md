# A value is one of several kinds or states

```json
{
  "standing": "accepted",
  "owes": [
    {
      "principle": "the-type-checker-proves-it"
    },
    {
      "principle": "our-code-reads-in-the-common-language"
    },
    {
      "rule": "kinds-are-named"
    }
  ]
}
```

A closed union of our own, a name per kind, no catch-all. Absence or a true-or-false that stands for a state is a named kind.
