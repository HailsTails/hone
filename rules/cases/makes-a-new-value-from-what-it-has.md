# Makes a new value from what it has

```json
{
  "standing": "accepted",
  "owes": [
    {
      "principle": "no-hidden-effects"
    },
    {
      "principle": "one-place-decides"
    }
  ]
}
```

It returns a new value. Nothing it was given or already made changes after it is made. A stream is drained only in its source's adapter, at a recorded site.
