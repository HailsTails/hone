# Names something

```json
{
  "standing": "accepted",
  "owes": [
    {
      "principle": "our-code-reads-in-the-common-language"
    },
    {
      "principle": "one-place-decides"
    },
    {
      "rule": "one-word-everywhere"
    }
  ]
}
```

The domain's word, the same everywhere, at every scope. Values that travel together are named fields, never a position. If only a generic word fits, split it. An outside contract's names stay in its boundary.
